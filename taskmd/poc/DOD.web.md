## Definition of Done — tareas web (v0)

propios de cada `TASK.md`. Se resuelven contra el mismo catálogo de plantillas.

`technical_done = (todos los AC en PASS) AND (toda esta DoD en PASS)`.

requiere actualizarlo — ver §11.7 / §13 #2 del spec.
